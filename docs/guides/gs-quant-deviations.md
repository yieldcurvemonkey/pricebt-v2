# Deliberate deviations from gs_quant

pricebt ports the Strategy / Trigger / Action / TransactionModel / CashAccrualModel / RelativeDate concepts of `gs_quant.backtests` under Apache-2.0 (see `NOTICE`); this file lists where it deliberately behaves differently.
Only differences verified against the gs_quant source and against pricebt's code and tests are listed; the `pricebt.backtests` facade keeps the gs_quant names and positional field orders, and an extension keeps the gs_quant behaviour as its default.
Test ids are `file::test` relative to `tests/`; code locations are relative to `src/pricebt/`; "gs" below means gs_quant.
